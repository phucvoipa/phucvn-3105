# 3105 x PHUCVN

Phiên bản tùy biến của **ThreeOneOSFive (3105)** dành cho iOS bởi **PHUCVN**.

## Tự động Build IPA trên GitHub Actions

Dự án đã được tích hợp sẵn GitHub Actions workflow tại `.github/workflows/build.yml`.

### Cách kích hoạt build:
1. Khi push mã nguồn lên nhánh `main` hoặc `master`, GitHub Actions sẽ tự động kích hoạt tiến trình build.
2. Hoặc bạn có thể kích hoạt thủ công trong mục **Actions** -> Chọn workflow **Build 3105 x PHUCVN IPA** -> Nhấn **Run workflow**.

### Tải file IPA sau khi build:
1. Vào tab **Actions** hoặc mục **Releases** trên GitHub repository.
2. Tải về file `3105-x-phucvn-unsigned.ipa`.
3. Cài đặt file IPA này vào iPhone/iPad thông qua TrollStore, AltStore, Sideloadly hoặc Scarlet.
